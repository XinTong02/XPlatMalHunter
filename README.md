# XPlatMalHunter
This repository contains the dataset roster (list of accounts) for the paper “Seeing Beyond GitHub: Boosting Malicious Developer Detection via Cross-Platform Signals”.
To protect privacy and data security, the public data released in this repository has been anonymized, and the full list is not publicly available.
If you need access to the complete list for legitimate research purposes, please contact me via private message and provide your reason, intended use, and data handling plan.🥸
